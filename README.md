# Alex Nieves

Live demos of my public projects. Each one runs in the browser, with nothing to install.

- **[FrontierBench and frontier-fly](https://alexnieves-cs.github.io/frontier-fly/)**: a benchmark for drones that explore buildings they have never seen, with a live scoreboard and flight replays. [Code](https://github.com/alexnieves-cs/frontier-fly)
- **[Propwash](https://alexnieves-cs.github.io/propwash-fpv/)**: an FPV drone simulator with Acro mode, freestyle scoring and ghost races. [Code](https://github.com/alexnieves-cs/propwash-fpv)
- **[Drift School](https://alexnieves-cs.github.io/drift-school/)**: draw a racetrack and watch RC cars train on it. [Code](https://github.com/alexnieves-cs/drift-school)
- **[Terminal Canvas](https://alexnieves-cs.github.io/terminal-canvas/)**: a macOS app where coding agents run in real terminals on an infinite canvas. [Code](https://github.com/alexnieves-cs/terminal-canvas)
